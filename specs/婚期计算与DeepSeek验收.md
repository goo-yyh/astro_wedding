# 婚期计算与 DeepSeek 验收

2026 年 11 月 24 日，北京时间。本次验收针对本机运行的 Astro Node 生产构建，使用虚构生日和家庭安排。桌面与手机尺寸均通过 Chromium 实操；DeepSeek 成功场景使用实际服务，故障场景使用隔离的测试服务或浏览器网络模拟。

## 婚期计算

| 检查 | 依据及结果 |
|---|---|
| 公农历、星期 | 将 2023–2029 年 2,557 天逐日与香港天文台英文年度表比对，覆盖 87 个闰月日期。公历转农历、农历转公历及星期均一致。 |
| 四离四绝 | 从同一独立对照表提取二分二至及四立，核对前一公历日。七年中各 28 天，全年扫描没有漏标或多标。 |
| 行嫁月份 | 十二生肖分别遍历十二个月，并测试仅大利月与同时接受小利月两种设置，共 288 种组合。 |
| 日级规则 | 遍历 2027 全年，按本站选用的 lunar-typescript 1.8.6 宜忌、吉神和建除字段核对嫁娶、不将和值日。另用固定避日表及六十日循环核对三娘煞、杨公忌、生肖冲日和入选资格。 |
| 家庭条件与排序 | 验证资料缺失、已知冲突优先排除、普通及闰月生日、场地可用及避开区间、同分排序、零分、无依据和全部排除。计算在 UTC、北京时间和洛杉矶时区得到相同样例首选。 |

香港天文台提供历法对照。黄历宜忌及婚嫁月份按本站公布的版本验收。[香港天文台公历农历对照表](https://www.hko.gov.hk/en/gts/time/conversion.htm)

## 评分与返回格式

结果页首选、日期清单和两日比较共用日期字段 `date`、`status`、`score`。报告汇总字段为 `dates`、`recommendedDate`、`topScore`、`tiedDates`。完整报告以全部候选日为范围，比较报告以选中的两天为范围。AI 接口以 `version`、`ok`、`data`、`error` 包装成功和失败响应。AI 选择需要对照的规则，程序保留评分和首选的决定权。

必须条件优先。通过后，各偏好组内先平均，再按组等权换算为整数百分制。偏好资料未填时展示缺项，跳过该条。有效 0 分与缺分（null）分别表示“已评但偏好均未满足”和“暂不评分”。同一最高分保留并列清单，较早的一天首列。

**手算基准。** 属兔新娘，2024 年 7 月 12 日，开启行嫁月、避三娘煞、避杨公忌、周五优先，以及缺资料的父母生日偏好。小利月得 50%，两个传统项目一项符合得 50%，星期偏好得 100%。三组平均后为 67 分，程序返回 67 分。

**浏览器样例。** 双方生日分别为 1994-05-12、1995-09-18，范围为 2026-11-25 至 2027-05-23。默认条件得 46 天可推荐、134 天已排除，首选 2027-05-09（94 分），与 2027-05-15（89 分）比较时分数保持一致。把避开四位父母生日设为必须，仅填两位后，变为 45 天待核对、135 天已排除，首选为空。[结果页截图](../output/playwright/婚期评分验收.png)

## DeepSeek 与浏览器

| 场景 | 核对结果 |
|---|---|
| 解析真实备注 | “最好周六”保留偏好属性；同一家酒店两个可选日期进入同一条档期条件。外婆可出席时间未知时返回待确认项。 |
| 真实两日对照 | 选取有效的规则标识，返回与本地计算相同的日期、分数、首选和并列清单。真实服务多次返回的关注项可以不同。 |
| 桌面与手机尺寸 | 桌面验证候选清单、分项评分、月历、两日解读和父母资料缺口。390 像素手机视口验证农历闰月生日、备注逐条应用、周六要求与酒店仅周日可用的冲突，以及结果页宽度。 |
| 错误与恢复 | 无密钥实测返回 503；隔离模拟上游限流、服务异常、约 32 秒超时、异常 JSON 和不存在的规则标识，均返回结构化错误。浏览器模拟网关错误仍保留计算结果，恢复正常接口后成功重新获取解读。 |
| 构建与密钥 | 类型检查通过，生产构建通过，10 组自动化测试通过。已核对 .env 受 Git 忽略，构建产物未发现配置中的密钥值。 |

## 复验

项目根目录执行下列命令。最后一个命令需先启动本地网站并配置 DeepSeek，会实际调用模型。

```sh
npm run check
npm test
npm run build
node --experimental-strip-types scripts/verify-hko.mjs
# 另一个终端启动 npm start 后执行
node --experimental-strip-types scripts/verify-deepseek.mjs
```

历法复验可用 HKO_TABLE_DIR 指向已下载的 2022 至 2029 年文本表（文件名如 2027.txt），其中 2022 年底的数据用于确定 2023 年初所在农历月。线上域名、反向代理及公网部署需在实际部署后另验。
